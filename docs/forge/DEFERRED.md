| # | Idea | Source | Spec/ADR | Rank |

| 15 | Fixed slot layout + private-non-inherited fields (ADR-0011) forecloses (a) adding a field to a *live* class / `become:`-style reshape (offsets are frozen at class-definition time) and (b) shared *protected* inherited fields (a subclass must go through accessors, never a shared offset). | 16 | The `Counter.new()` → `construct` selector redirect (`VM.constructor_aliases`/`has_new_construct`) is a **compile-time, same-compilation-unit, literal-receiver** heuristic: it only fires when the call site's receiver is a bare `Expr::Var` naming the class *and* that class's `construct`(s) were already compiled earlier in the same source. An indirect receiver (`let C = Counter; C.new()`), a forward reference, or a cross-module call falls back to the plain `Method`-encoded selector — for a class with no matching `new` primitive of its own this silently reaches `Object::new`'s bare allocator again, uncaught. A real fix needs either static class-type tracking through locals or a runtime dispatch rule (e.g. always trying the `Initializer` encoding before `Method` at every send), not a compiler-side name match. | `phalcom-core/src/compiler/lib.rs` (`Expr::MethodCall`) | ADR-0011 | med |

## Surfaced during U-LIST implementation (2026-07-11)
| # | Idea | Source | Spec/ADR | Rank |
|---|------|--------|----------|------|
| 17 | **`Statement::Class` unconditionally emits `DefineGlobal` at the end of every class body, reopen or not** (compiler/lib.rs). Harmless for every core class whose global already points at that class object, but `None`'s global is deliberately bound to the shared singleton *instance*, not the class (`VM::install_core`) — so a `class None { ... }` reopen silently clobbers that binding back to the class the moment `core.ph` runs, breaking every `x == None` comparison downstream. U-LIST worked around it by dropping the empty, purposeless `class None {}` skeleton from `core.ph` (nothing was lost — it had no members). **Whoever next needs real members on `None` must fix this compiler special case first** — e.g. skip `DefineGlobal` when reopening a class whose current global binding is not that same class object — not just re-add the reopen. | `phalcom-core/src/compiler/lib.rs` (`Statement::Class`, ~L862) | — | high |
| 18 | `List::rawSet` (indexed write) is implemented and wired as a primitive (`primitive/list.rs`) but has no `.ph` wrapper this unit — no `at(_:put:)` selector exists yet. Candidate for U-STD to surface with a one-line `.ph` method (`at(i, v) { self.rawSet(i, v) }` or similar labeled-arg spelling). | U-LIST-plan §3/§4 | ADR-0020 | med |
| 19 | `List.toString` is a **native primitive** (`primitive/list.rs::list_to_string`), not `.ph`-defined over `each(_:)` as the plan's sketch suggested — because no kernel value type has a general user-callable `.toString` yet (e.g. `Number` only inherits `Object`'s default `"<ClassName>"` getter, never its actual numeric value). Building `List.toString` in `.ph` today would render every non-`String` element wrong.
