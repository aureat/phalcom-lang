# Phalcom Collections and Argument-Pack Specs

This directory contains a structured draft specification suite for:

- tuples;
- records;
- sets;
- argument packs;
- `*`, `**`, and `***` rest/spread operators;
- callable domains;
- reflective Type values;
- normalization and subtyping;
- diagnostics;
- conformance tests;
- open-question and gap analysis.

Start with [`00-index.md`](00-index.md).

The suite deliberately distinguishes **RATIFIED**, **AMENDED**, **PROVISIONAL**, and **OPEN** rules so a follow-up reviewer can identify which parts reflect explicit decisions and which parts are consistency recommendations.
