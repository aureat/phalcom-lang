# Phaldoc and documentation

> Sources: DOCS001, DOCS003
> Raw: [tooling program snapshot](../raw/tooling/2026-09-08-tooling-sources.md)
> Updated: 2026-09-08

Phaldoc extracts documentation-facing declarations and produces navigable output. Documentation organization supplies stable category/program/checkpoint/plan ownership for implementation records without upgrading their status.

## Boundary

Documentation prose and annotations are not formal semantic evidence. The generator may preserve source locations and declaration links, while [semantic editor products](../editor/semantic-editor-products.md) decides how an IDE presents canonical facts.

DOCS001 is in progress and partial; DOCS003 is proposed and unverified.
