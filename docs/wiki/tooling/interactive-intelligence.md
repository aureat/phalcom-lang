# Interactive intelligence

> Sources: CLIT001; semantic consumer rules
> Raw: [tooling program snapshot](../raw/tooling/2026-09-08-tooling-sources.md)
> Updated: 2026-09-08

Completion, hover, diagnostics, and inspection in an interactive session are projections of canonical semantic products. They must be pinned to the session's source revision and must preserve uncertainty rather than guessing from terminal text.

[Semantic editor products](../editor/semantic-editor-products.md) owns the shared projection boundary; [REPL sessions](repl-sessions.md) owns context. CLIT001 is proposed and unverified.
