# Collections

> Sources: collections specifications and COLL001–COLL005
> Raw: [collection specification and program snapshot](../raw/collections/2026-09-08-collections-sources.md)

The collections domain defines product values, maps, indexed access, ranges, traversal, and argument expansion. It neighbors [language](../language/overview.md) for literals and call syntax, [type-system](../type-system/overview.md) for product/row types, [runtime](../runtime/overview.md) for representation, and [standard-library](../standard-library/overview.md) for library protocols.
