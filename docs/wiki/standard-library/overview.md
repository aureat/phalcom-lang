# Standard library

> Sources: numeric conformance and standard-library specifications; STDL001–STDL002
> Raw: [standard-library specification and program snapshot](../raw/standard-library/2026-09-08-standard-library-sources.md)
> Updated: 2026-09-08

The standard-library domain defines user-facing numeric, collection, bytes, stream, filesystem, network, cancellation, and reactor contracts. It neighbors [native](../native/overview.md) for host primitives, [runtime](../runtime/overview.md) for execution, [collections](../collections/overview.md) for value protocols, and [diagnostics](../diagnostics/overview.md) for errors.

## Reading order

- [Numeric contracts](numeric-contracts.md)
- [Collection library surface](collection-library-surface.md)

STDL001 is in progress and partial; STDL002 is a proposed buildout. Normative specifications and implementation status remain separate.
