This is the authoritative "what we chose" layer — when the generic reference lists options, this says which one Phalcom took and why it's locked. Update when an ADR lands or an open question resolves.

## Hazards Phalcom has already hit (canonical case studies)
- **default args ⊗ selector-identity dispatch** — omitting a defaulted arg produces a *different* selector, so lookup misses the full-arity method. Only fixes were combinatorial arity-family expansion or unavailable static callee knowledge. Status: ✅ **resolved by [ADR-0043](../../../../docs/adr/0043-no-default-arguments-keep-selector-identity-pristine.md) (Accepted) — by declining the feature.** Manual arity-overload is the idiom. Re-adding defaults requires a superseding ADR that shows dispatch-table registration without regressing the single probe.
- **Option bootstrap cycle** — fields default to `None`, but constructing `None` seemed to need a class whose fields default to `None`. Status: ✅ **dissolved by [ADR-0044](../../../../docs/adr/0044-option-bootstrap-formalization-and-defer-niche-encoding.md) (Accepted)** — `None` is fieldless, so the field-default rule never re-enters its construction. No code change was needed; the tree was already correct. The *performance* half (niche-encoding) is deferred.
- **truthiness ban without flow analysis** — banning `if(opt)` has no static analyzer to enforce it. Status: ✅ **resolved by [ADR-0021](../../../../docs/adr/0021-no-truthiness-enforcement.md) (Accepted)** with **both** halves of the generic recipe: a runtime `GuardBool` floor *plus* compile-time rejection of syntactically-literal Option conditions. Accepted gap: indirection (`var x = None; if (x)`) is caught only at runtime.
- **speculative inlining ⊗ late binding** — inlining `ifTrue:`/`whileTrue:` assumes they aren't overridden. Status: ✅ **resolved by [ADR-0018](../../../../docs/adr/0018-sacred-selector-inliner-and-override-guard.md) (Accepted)** — per-family pristine flag flipped by `note_method_installed`; once flipped the deopt path is a real send, so the override wins. Guard failure is observably identical to the slow path.
- **inline cache ⊗ mutable hierarchy** — Status: ✅ **sidestepped by [ADR-0026](../../../../docs/adr/0026-class-hierarchy-mutability.md)/[ADR-0041](../../../../docs/adr/0041-hierarchy-stability-policy.md)**. Superclass reparenting is *forbidden*, so a future IC keys on `ClassId` with no invalidate-on-reparent case. Sealing is the substitute for an epoch scheme on that axis; method mutation keeps ADR-0018's guard.
- **stackful fibers ⊗ moving GC** — Status: ✅ **does not arise.** [ADR-0030](../../../../docs/adr/0030-fibers-and-futures-cooperative-concurrency.md) uses no native fiber stacks, which is precisely what preserves ADR-0009's "a moving GC can drop in behind handles" claim. But note ADR-0050 (Proposed) *chooses non-moving* and demotes moving to a rejected-for-now alternative — the overlay's moving-GC optionality is mechanically intact, directionally stale.
- **kernel `List` is an unscheduled hard dependency** — Status: ✅ **fully resolved.** [ADR-0020](../../../../docs/adr/0020-kernel-list-native-array-protocol.md) **and** its dependency [ADR-0019](../../../../docs/adr/0019-freeze-vm-blessed-primitive-floor.md) are both **Accepted** (the pre-2026-07-14 overlay claimed both were "Proposed, ratification still pending" — that was wrong). Promoted to a committed row above.
- **`static` naming collision** — Status: ✅ resolved, shipped as [ADR-0017](../../../../docs/adr/0017-class-side-stored-static-fields.md) (Accepted): class object gets its own `static_slots`, indexed by the metaclass field table.
- **`ifTrue`/`ifFalse` → `Option` breaks chaining** — `cond.ifTrue{a}.ifFalse{b}` sends `ifFalse` to an `Option`. Status: **open-Q1 note / selectors §7.2.** ADR-0018's U-CORE-2 amendment adds `Some`-lifting for one-armed conditionals; the two-armed atomic form is the recorded surface decision.
- **`var x` = `None` reintroduces `nil` under a new name** — every var becomes `T | None`. Status: **open-Q1 note / selectors §7.1, resolution stands but flagged.**
- **non-local `return` across a fiber boundary** — *Handled by construction*: generation mismatch raises `DeadFrameError`. Ref: ADR-0013, ADR-0030.
- **`Rc<RefCell>` cycle-leak + double-borrow panic (F5/F1-class)** — *Removed by construction* via the handle heap. Ref: ADR-0009 (F5).
- **audit findings folded into ADRs, not patched piecemeal** — F1, F7, F8 fixed inside ADR-0012; F4 in ADR-0015; F9/F10 in ADR-0016.

## Performance & security posture (→ performance.md, security.md)
| Axis | Phalcom's stance | Where | Note |
|---|---|---|---|
| Dispatch cost | Inline-cache-*ready* (per-site slot keyed by `ClassId`); population deferred | ADR-0012 | Today every send walks the dict. No `InlineCache` in tree as of 2026-07-14 |
| Value repr / boxing | Tagged Rust `enum`; NaN-boxing + Option niche-encoding deferred behind the same `Value` API | ADR-0010, ADR-0044 | Only `Some`/heap objects allocate; `Number`/`Bool`/`Symbol`/`nil` inline |
| GC / ownership | Handle/arena `Heap`, `Copy` `ObjRef`/`ClassId`; no `Rc`/`RefCell` | ADR-0009 | ADR-0050 (**Proposed**) selects non-moving precise mark-sweep: marks in a `SecondaryMap` side table, no relocation, no write barrier, safepoint-latched. Handles stay stable ⇒ ICs, `==` identity, and parked fiber `Value`s survive collection. Moving/compacting is "kept reversibly open, not taken now" |
| Speculative opt | Sacred-selector inliner + receiver guard + override-epoch deopt | **ADR-0018 (Accepted)**, control-flow §3 | Fast path must equal the slow send exactly; deopt materializes the block. Verified by named tests |
| Performance discipline | **Proposed**: no optimization lands without (a) an in-repo reproducible benchmark, (b) a profile attributing cost to a named mechanism, (c) a recorded before/after number. Tier 0–6 order; target Wren parity (~2×) on Skynet | ADR-0051 | Behavior-invariant: golden `.ph` corpus stays byte-identical. A perf change that alters an observable is a spec change needing its own ADR, not a "performance sneak" |
| Concurrency safety | Cooperative single-threaded; `Fiber` only | ADR-0030, concurrency §1–2 | No preemption ⇒ no data races by construction |
| Memory safety | Rust ownership + handle heap; **no `unsafe` for the object graph** | ADR-0009 | Cyclic apex done via handle patches, not raw pointers/`unsafe` |
| Robustness substrate | Golden `.ph` corpus + snapshot + fuzz + miri lanes; `verify_invariants()` | forge STATE.md / stabilizer | Every `panic!` on user input is a robustness bug → turn into a diagnostic |
| Untrusted input | Hand-written lexer + recursive-descent parser, panic-mode recovery (no crash) | ADR-0016 | Parser hardened + multi-error; bytecode is compiler-produced, not externally loaded — **so no verifier is needed yet**, but one becomes mandatory if anything ever loads a *compiled* unit rather than compiling from source |

**Open perf/security questions:** IC population, NaN-boxing, Option niche-encoding (all deferred behind committed APIs); GC is Proposed only (ADR-0050); no external-bytecode loader (ADR-0045 imports resolve *source* paths); resource limits (stack depth / allocation caps) unspecified.
